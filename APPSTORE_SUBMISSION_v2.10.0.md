## App Store Optimization (ASO) Strategy

### Target Search Terms & Optimization
To maximize discoverability for users searching "json format", "parquet view", and "sql format":

#### 1. **App Name & Subtitle** (Highest Impact)
- **App Name**: DevUtilities
- **Subtitle**: "JSON, SQL, Parquet Formatter" (28 chars)
  - Directly includes all 3 target keywords
  - Shows in search results prominently
  - Alternative: "JSON SQL Parquet Tools" (26 chars)

#### 2. **Keywords Field** (Critical for Search)
```
json format,sql format,parquet view,json formatter,sql formatter,developer tools,base64,converter
```
- Use both "format" and "formatter" variations
- Include exact phrases users search for
- Avoid spaces after commas (counts toward limit)

#### 3. **Description Optimization**
The first 170 characters (what shows before "more") MUST include all keywords:
- ✅ "JSON FORMATTER • SQL FORMATTER • PARQUET VIEWER"
- ✅ "JSON format, SQL format, and Parquet view tasks"
- Repeat keywords naturally throughout description (3-5 times each)
- Use variations: "format JSON", "beautify JSON", "view Parquet files"
