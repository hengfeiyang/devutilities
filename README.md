# DevUtilities

DevUtilities is a native macOS toolkit that brings 25 developer utilities into one workspace, covering data formatting, text comparison, conversions, network requests, cryptography, and AI assistance.

[Website](https://hengfeiyang.github.io/devutilities/) · [Download on the Mac App Store](https://apps.apple.com/app/devutilities/id6753612551)

Visit the website for tool introductions, screenshots, and [release notes](https://hengfeiyang.github.io/devutilities/release-notes.html).

## Official app and Pro

The official Mac App Store app is the recommended way to use DevUtilities. Supporting the official version helps fund continued development and maintenance.

The upcoming 3.0 release moves to free download with 18 permanently free tools and seven Pro tools: AI Chat, AI Translate, Parquet, IP Lookup, Currency, JWT, and Crypto.

Start a 30-day Pro trial when you are ready. After the trial, unlock those seven tools with a one-time Lifetime Pro purchase. There is no recurring subscription, and the 18 free tools remain available.

Early Supporters who first acquired the app from January 1, 2025 through October 24, 2026 receive permanent Pro, whether the original download was paid or free.

AI features require your own provider credentials; external AI service charges are separate from Lifetime Pro.

## Project

The app source and website are maintained together in this repository. The app is built with SwiftUI for macOS 15 and later; the static website lives in `website/`.

For feedback and bug reports, use this repository's [Issues](https://github.com/hengfeiyang/DevUtilities/issues).

## Local development

Open `DevUtilities.xcodeproj` in Xcode and click Run to build and run the app locally.
